# 개인정보처리방침 - 다섯 줄

화면 맨 아래에 `개인정보처리방침` 링크를 걸고, 그 페이지에 아래 다섯 줄을 넣는다.
`{ }` 안만 자기 것으로 바꾼다.

---

## {서비스 이름} 개인정보처리방침

1. **무엇을 받나** - 구글 로그인으로 이메일, 이름, 프로필 사진을 받습니다.
2. **왜 받나** - 로그인한 분을 알아보고 그분이 남긴 내용을 보여드리기 위해서입니다.
3. **언제까지 두나** - 계정을 지우시면 즉시 삭제합니다. 이 서비스는 {수업 종료일} 에 전체 삭제됩니다.
4. **누가 대신 처리하나** - 로그인 확인은 Google 이, 데이터 보관은 Supabase 가 대신합니다.
5. **문의** - {본인 이메일}

---

## 왜 다섯 줄인가

5기 게이트 1은 8항목을 요구한다(수집 항목 / 목적 / 보관 기간 / 제3자 제공 / 처리 위탁 /
정보주체 권리 / 책임자 / 변경 고지). 위 다섯 줄이 그중 실습 앱에 실제로 해당하는 것을 덮는다.

- 제3자 제공은 **하지 않으므로** 3번에 "전체 삭제"로 갈음한다. 남에게 넘기면 그 줄을 추가한다.
- 정보주체 권리는 화면의 **지우는 버튼**이 실물이다. 문장만 쓰고 버튼이 없으면 위반이다.

수업 실습을 넘어 실제 서비스로 운영하면 8항목 전체를 쓴다.
