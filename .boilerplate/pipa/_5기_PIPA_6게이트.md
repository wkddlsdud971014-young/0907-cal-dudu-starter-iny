# PIPA - 회원가입 받는 즉시 적용
## PIPA가 무엇이고 언제 적용되는지 (1/3)
### 한국 개인정보보호법 (PIPA)
회원가입 = 사용자의 개인정보(이메일 / 이름 / 프로필) 수집입니다. 한국에서 개인정보 수집은 PIPA(개인정보보호법) 적용 대상입니다.
PIPA 핵심 사실:
- 모든 회원가입 사이트 / 앱 적용
- 사업자등록 여부 무관 (개인 사이트도 적용)
- 위반 시 과태료 / 과징금 / 사용자 손해배상 청구
### Google OAuth + PIPA 처리위탁
본인이 직접 이메일/비밀번호 폼을 만들지 않고 Google 로그인을 받았습니다. 이 경우 Google = 본 서비스의 처리위탁자입니다.
위탁 의무 세 가지입니다.
- 본인 처리방침에 "Google에 인증 처리를 위탁한다" 한 줄 명시
- Google이 받는 정보(이메일 / 이름 / 프로필 사진) 명시
- 본인 서비스가 Google에서 받은 정보를 어떻게 사용하는지 명시

# PIPA 6 게이트
## 처리방침 / 이용약관 / 동의 / 14세 미만 / 주민번호 / 위반 페널티 (2/3)
### 게이트 1 - 처리방침 8 항목 공개
웹사이트 / 앱 footer에 "개인정보처리방침" 링크 + 다음 8 항목 작성합니다.
1. 수집 항목 (이메일 / 이름 / 프로필 사진)
2. 수집 목적 (서비스 제공 / 회원 식별)
3. 보관 기간 (회원 탈퇴 시 즉시 또는 일정 기간)
4. 제3자 제공 (제공 안 함 / 제공 시 누구에게)
5. 처리 위탁 (Google = 인증 처리 위탁)
6. 정보주체 권리 (열람 / 정정 / 삭제 / 처리 정지)
7. 개인정보보호 책임자 (이름 / 연락처)
8. 처리방침 변경 시 고지 방법
### 게이트 2 - 이용약관
서비스 내용 + 회원 의무 + 운영자 의무 + 책임 한계 + 분쟁 해결 절차
### 게이트 3 - 회원가입 시 동의
이용약관 + 개인정보처리방침 동의 (필수) + 마케팅 수신 동의 (선택, 분리 표기 의무)
Google OAuth는 회원가입 폼이 없으므로 첫 로그인 후 동의 페이지로 처리합니다.
### 게이트 4 - 만 14세 미만
만 14세 미만 사용자는 법정대리인 동의 필수입니다 (PIPA).
### 게이트 5 - 주민번호 수집 금지
주민번호는 법령 근거 없이 수집 금지입니다. 본인 인증이 필요하면 휴대폰 본인인증 또는 이메일 인증으로 대체합니다.
### 게이트 6 - 위반 페널티
- 동의 미획득: 5,000만원 이하 과태료
- 처리방침 미공개: 3,000만원 이하 과태료
- 안전성 확보 조치 위반: 1억원 이하 과징금
- 사용자 손해배상 청구 (집단 소송 가능)

# biz matrix - 회원가입 = 고객 자산화의 시작점
## 회원가입 후 따라오는 변화 + 본인 사업 funnel (3/3)
### biz matrix 슬라이드
회원가입 받기 전 = 비회원 매장입니다 (방문 끝나면 사용자 사라집니다).
회원가입 받은 후 = 회원 매장입니다 (사용자 누적 / LTV / 리텐션 측정 가능).
biz matrix 키워드 네 가지입니다.
- LTV (누적 회원 수 × 평균 결제액)
- 리텐션 (재방문률)
- 전환율 (방문자 → 회원)
- 고객 자산 (재방문 + 결제 가능한 모집단)
### 회원가입 후 따라오는 6 게이트
biz 의미: 게이트 6개 = 회원가입을 사업으로 운영하기 위한 진입 자격입니다.
- 게이트 1-2 = 문서 작성 (처리방침 + 이용약관)
- 게이트 3 = UX 추가 (동의 페이지)
- 게이트 4-5 = 사용자 검증 (Google 위탁이라 본인 손에 직접 안 들어옴)
- 게이트 6 = 페널티 인지 (위반 시 손실 규모)
### 본인 사업 funnel
사업 입장에서 회원가입은 funnel의 한 단계입니다.
방문 → 회원가입 → 첫 행동 → 재방문 → LTV 누적
회원가입 단계가 빠지면 누적 사용자 = 0입니다. 사업 자산 = 0입니다.
