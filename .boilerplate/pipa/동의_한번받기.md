# 첫 로그인 때 동의 한 번

구글 로그인에는 가입 폼이 없다. 그래서 **로그인 직후 화면**에서 동의를 한 번 받는다.
5기 게이트 3이 요구하는 것이고, 없으면 동의 미획득이다.

## 만드는 것

로그인 직후, 아직 동의하지 않은 사람에게 화면 하나를 띄운다.

- 체크박스 한 개 - `개인정보처리방침에 동의합니다 (필수)` + 처리방침 링크
- `시작하기` 버튼 - 체크 전에는 눌리지 않는다
- 체크하고 누르면 동의 시각을 남기고 본 화면으로 보낸다

## 동의 기록을 어디 두나

표 하나를 더 만들지 않는다. Supabase 사용자 메타데이터에 한 줄 남긴다.

```
supabase.auth.updateUser({ data: { privacy_agreed_at: new Date().toISOString() } })
```

다음 로그인부터 이 값이 있으면 동의 화면을 건너뛴다.

## 마케팅 동의

실습에서는 **받지 않는다.** 광고를 보내지 않기 때문이다.
보내려면 필수 동의와 **줄을 나눠** 따로 받아야 한다(게이트 3, 분리 표기 의무).
